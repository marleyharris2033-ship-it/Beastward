# Beastward

**Hatch. Evolve. Defend.**

Beastward is a creature-collecting tower defence game prototype.

## Current build

- Pick one of three starters: Embercub, Sprigpaw or Bubblit
- Beast level cap of 30
- Evolutions at Level 20 and Level 30
- Beast Sanctuary hub
- First campaign stage: Keeper's Path
- Ten waves and a Wave 10 boss
- Essence rewards
- Mobile-friendly touch placement
- Bespoke Beastward-style title screen

## Planned next

Egg rarities, Hatchery, more beasts, permanent XP progression, tower upgrade branches and bespoke creature sprites.
